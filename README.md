# 부고 공문 개인정보 가리기 (nanum-obit-masking)

관공서에서 받은 부고·장례 관련 공문(HWP, HWPX, PDF, 팩스 이미지)에서 이름·주민등록번호·전화번호·주소를 **PC 안에서** 찾아 가린 사본을 만드는 프로그램입니다. 사람이 검수 화면에서 확인하고 승인한 사본만 Claude 같은 AI 도구가 읽도록 해서, 원본의 개인정보가 PC 밖으로 나가지 않게 합니다.

- 인터넷을 쓰지 않습니다. 글자 인식(OCR)과 이름 찾기 모델은 설치할 때 한 번만 받고, 그 뒤에는 프로그램 안의 차단 장치와 Windows 방화벽으로 바깥 연결을 막습니다.
- 화면과 기록 파일에는 값을 쓰지 않고 건수와 상태만 씁니다.
- 검수에서 찾은 오류는 "오답 노트"에 쌓여 다음 문서부터 반영됩니다. 쉬운 것은 자동으로 반영하고, 정규식(글자 규칙)을 고쳐야 하는 것은 Claude Code가 가짜화한 요청만 보고 수정안을 쓴 뒤 직원이 승인합니다.

## 시험 결과 (가짜 공문, 맥에서 측정)

| 형식 | 건수 | 놓친 개인정보 | 장당 처리 시간(CPU) |
|---|---|---|---|
| 텍스트 PDF | 8 | 0 | 0.44초 |
| HWPX | 2 | 0 | 0.26초 |
| 스캔 PDF | 8 | 0 | 3.16초 |
| 팩스 이미지 | 8 | 0 | 11.16초(첫 장은 모델을 읽느라 약 20초) |

최대 메모리는 2.3GB였습니다. **Windows PC에서는 아직 실행해 보지 않았습니다.** 설치 마지막 단계의 자체 시험으로 같은 기준(놓침 0건)을 다시 확인합니다.

## 설치

Windows 11 PC에 Claude Code가 있으면, 이 저장소의 [`INSTALL-ClaudeCode.md`](INSTALL-ClaudeCode.md)를 Claude Code에 주고 이렇게 말하면 됩니다.

> https://github.com/picoco1145/nanum-obit-masking 의 INSTALL-ClaudeCode.md 대로 C:\nanum-mask 에 설치해 줘.

필요한 것: Windows 11, 디스크 여유 4GB, 설치하는 동안의 인터넷 연결, 관리자 권한(방화벽 규칙을 넣을 때 한 번). GPU는 쓰지 않습니다.

## 매일 쓰는 방법

1. 받은 공문 파일을 바탕화면의 **받은 공문 넣는 곳**(`C:\nanum-mask\inbox`)에 넣습니다.
2. 바탕화면의 **공문 가리기**를 실행합니다. 공문을 가린 뒤 검수 화면이 브라우저에 열립니다.
3. 문서마다 가린 곳을 확인합니다. 놓친 글자는 끌어서 선택한 뒤 종류 단추를 누르고, 잘못 가린 곳은 눌러 표시합니다.
4. **저장하고 승인**을 누르면 표시를 반영한 사본이 `masked` 폴더로 갑니다. 팩스는 반드시 사람이 확인한 뒤 승인합니다.
5. Claude에게는 "masked 폴더의 공문을 정리해 줘"처럼 가린 사본만 읽게 합니다.

검수 화면의 **오답 노트 반영**은 표시를 모아 다음 문서부터 반영합니다. 매주 `app\learn.py report`로 주간 보고(놓침·과잉 건수, 자동 반영한 낱말, 승인 대기 수정안)를 확인합니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `app/` | 프로그램 코드(가리기, 글자 읽기, 정규식, 이름 찾기, 검수 화면, 오답 노트, 승인, 통신 차단 장치) |
| `config/` | 라벨 사전, 이름으로 오인하기 쉬운 낱말, 단체가 정할 기준(`policy.yaml`) |
| `tests/` | 가짜 공문 생성기, 단위 시험, 채점, 자체 시험(`selftest.py`) |
| `tools/` | 설치 때 한 번 쓰는 모델 내려받기 |
| `windows/` | 바탕화면 실행 파일과 아이콘 만들기 |
| `docs/` | 설계 문서(지시서 v2) |

설치하면 `inbox`, `pending`, `masked`, `secure`, `learn`, `logs`, `models` 폴더가 생깁니다. 이 폴더들은 저장소에 올리지 않습니다(`.gitignore`). 특히 `secure`에는 원본과 대조표가 들어가므로 PC 밖으로 내보내지 않습니다.

## 단체가 정할 것

`config/policy.yaml`에 적습니다. 정하기 전에는 더 안전한 쪽이 기본값입니다.

- 담당 공무원 이름과 기관 대표전화를 가릴지(기본: 가림)
- 원본과 대조표를 얼마나 보관할지(기본: 보관, 지우지 않음)
